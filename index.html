イベント誇父計画イベント追加

人類の生存空間を広げるため宇宙へ進出！2つの段階で進む新大規模イベント。

🚀 段階1：ロケット製造ルール
  1. 「宇宙開発設計図」を消費して製造。「ロケット」または「パーツ」を獲得。
  2. ロケットの品質が高いほど、搭乗できる宇宙飛行士の数がアップ！
  3. ロケット搭乗：グループ内の首長は1名の名士を派遣可能。宇宙服を消費して搭乗します。
  4. 宇宙服の品質：「希少」「伝説」「神話」の3種類。高品質ほど獲得報酬もアップ。
  5. 座席が満席になるとカウントダウンが5分に短縮。空席はNPCが自動補充。
🌌 第2段階：星間開拓ルール
  1. 開拓船を発射し、居住可能な星へ改造！
  2. 星の開拓繁栄度は「開拓ポイント」に変換され、銀河商店で豪華アイテムと交換可能。
  3. 星定住：改造成功した星には全首長（非開拓者含む）が定住可能（定住報酬あり）。
  4. 銀河帝国：繁栄度が5000万に達すると、自分だけの銀河帝国を建国可能！

新システム天工システム追加

起業投資会で投資・開発を行い、新たな「発明」を作成・展示して属性バフを獲得！

🔍 システム詳細・ルールを見る
  • 投資項目：毎日項目が更新。銅貨を消費して投資し、完了で報酬＆設計図を獲得。
  • 天機推演：霊墨を消費して項目の品質上昇に挑戦（最低保証機能あり）。
  • 創造発明：生産属性（経営・効率）や戦闘属性（名士・兵士強化）、特殊な「奇効」が付与。
  • 発明陳列：「天工館」の各枠に陳列することで属性バフと奇効が正式発動！
  • 取引センター：月間札を有効化している首長は、「取引所」で発明を売買可能（通貨：巧金）。

🌕 秋夜の宝探し（新イベント）

  • 月餅を切り分けて報酬を獲得！1箱全て切り終えると豪華な「大賞」を獲得。
  • イベント参加で新美女・衣装「神話瑤姫」が獲得可能！

💎 その他の新機能

  • 収集品精錬機能：伝説・神話品質の収集品を精錬可能に。
  • 名士神格システム：品質上昇能力を持つ名士の神格育成が開放！心魔を倒して境界突破。
  • 遠征攻城戦：撃破部隊数に応じて兵士戦力バフを獲得。
  • 便利機能：富貴栄華の自動貿易機能、精研・技巧のおすすめ研究など各種UI追加。
🛠️ 二、調整内容
  • 富貴栄華：商隊の自動貿易機能追加（八方招財・荊湖路開拓が必要）。メイン画面にショートカット投資追加。
  • 世界遠征：
    • 1期の継続時間を30日 → 45日に延長。
    • 途中で同盟変更時のクールダウン調整（1回目:1日 / 2回目以降:7日）。
    • 休戦期間中の中心城地への宣戦は毎週土曜日のみに変更。
  • イベントグループ化：慶余年、逐鹿の戦いなどの勢力グループ分けを最適化し、人数差を緩和。
🔧 三、不具合修復内容
  • 装備中の「収集品」も分解できるように修正。
  • 「巡回」で中州以外のマップで手動巡回時に画面が止まる問題を修正。
  • 「女媧の補天」で手動ターゲット切り替え後に技能を使うと対象が変わる問題を修正。
  • 「山海の幻境」で盟友の石発見状態が更新されない問題を修正。
  • 「戦闘」で斬殺系効果が体力減少の計算に含まれない問題を修復。
