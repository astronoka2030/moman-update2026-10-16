🚀 段階1：ロケット製造（クリックで詳細展開）

【基本ルール】

  1. イベント期間中、「宇宙開発設計図」を消費して実験工場で製造できます。
  2. 製造するたびに、ランダムで「ロケット」または「パーツ」のいずれかを獲得できます。
  3. 製造でロケットを獲得すると、道具報酬と発射用の「ロケット」を獲得できます。パーツを獲得すると、対応する道具報酬を獲得できます。
  4. ロケットにはさまざまな品質があり、品質が高いほど搭乗できる宇宙飛行士の数も増えます。

【ロケット発射】

  1. ロケットを入手したら、「発射基地」へ行って発射するロケットを選べます。
  2. ロケットを発射井に入ると、対応する「発射報酬」を獲得し、発射準備段階に入ります。

【ロケット搭乗】

  1. 発射準備期間中、同じグループの首長は1名の名士を宇宙飛行士として派遣し、ロケットに搭乗させて宇宙へ向かわせることができます。
  2. 名士が宇宙飛行士になるには、宇宙服を1着消費してロケットに参加する必要があります。各首長は同じロケット内で最大1つの座席を占有できます。
  3. 名士が搭乗した後、その名士は今回の発射集計前に他のロケットへは参加できません。
  4. 宇宙服は「希少」「伝説」「神話」の3種類の品質に分かれています。品質が高いほど、搭乗時に得られる報酬も高くなり、同時にロケット発射者への上昇報酬も多くなります。
  5. ロケットの座席が満席になると、カウントダウンは5分に短縮されます（すでに5分未満の場合は短縮されません）。発射準備のカウントダウン終了時に空席がある場合は、NPC宇宙飛行士が残りの座席を自動で補充します。
  6. ロケット発射後、搭乗した首長は対応する上昇報酬を獲得できます。発射者は、搭乗した全会員の宇宙服による追加報酬も獲得できます。

【順位ルール】

  1. 今回のイベントで獲得した「宇宙開発功績」は、「ロケット製造」番付の順位基準となります。
  2. ロケット製造段階の集計時、各グループの番付上位の首長は、次の段階「星間開拓」へ進む資格を獲得できます。
🌌 第2段階：星間開拓（クリックで詳細展開）

【星開拓】

  1. 開拓者になると、前段階の総ポイント順位に従って、開拓星港に出現します。
  2. 開拓者は開拓船を発射し、銀河系でランダムに1つの星を探索して、人類が住める居住可能な星へ改造できます。
  3. 開拓船の種類によって探索できる星の品質は異なり、各星は開拓時にランダム特質が発生し、最終的な星の開拓繁栄度に影響します。
  4. 星の改造完了後に発生する開拓繁栄度は、一定のルールに従って開拓ポイントに変換され、銀河商店で報酬道具と交換できます。
  5. 各開拓者が開拓した星の数が一定条件に達すると、すべての首長に対応する同慶報酬が配布されます（イベント期間中のみ受け取れ、この報酬は再配布できません）。

【星定住】

  1. 開拓者が星の改造に成功すると、定住権が期間限定で開放され、すべての首長（非開拓者を含む）はその星へ定住できます。
  2. 定住するたびに定住報酬を1つ獲得できます。各星につき、各首長は1回しか定住できません。
  3. 星の定住開放時間終了後、その星は定住申請を受け付けなくなります。

【銀河帝国】

  1. イベント期間中、開拓繁栄度が5000万に達すると、自分だけの銀河帝国を建国できます。
  2. 開拓者は帝国の名称、旗、帝国宣言を自由設定でき、イベント期間中に変更できるのは1回のみです。
  3. 銀河帝国を建国すると、銀河星図に帝国の勢力範囲が表示されます。開拓者の開拓繁栄度が高いほど、占有できる勢力範囲も広くなります。

【順位のルール】

  1. 開拓番付：イベント期間中、開拓者たちが累計で獲得した開拓繁栄度を順位の基準とします。
  2. 最強星番付：イベント期間中、開拓者自身の開拓星球のうち、開拓繁栄度が最も高い星を順位の基準とします。
  3. 開拓者でない首長は順位に参加できません。

新機能二、新たに天工システムを追加

⚙️ 天工システムの詳細・機能データベース（クリックで詳細展開）

【投資項目】

  1. 起業投資会では、毎日投資可能な項目が更新されます。
  2. 投資項目には一定数の銅貨を消費します。投資後、項目は研究段階に入り、完了すると対応する報酬を受け取れます。さらに、確率で「設計図」も追加で獲得できます。
  3. 未投資項目には上限があります。上限を超えると翌日0時に更新されなくなりますので、早めに投資してください！
  4. 各項目の投資を完了するたびに、一定数の「投資ポイント」を獲得できます。項目の品質によって、獲得できる投資ポイントも異なります。
  5. 投資ポイントが一定数たまると、「投資星レベル」を上昇できます。投資星レベルが高いほど、毎日投資項目を更新する際に、より良い項目が出やすくなります。

【天機推演】

  1. まだ投資を始めておらず、かつ最高品質に達していない項目は、「天機推演」で品質の上昇を試せます。
  2. 推演には一定数の「霊墨」を消費します。項目の品質によって、必要数は異なります。
  3. 推演には成功確率があります。成功すると項目の品質が上昇し、失敗した場合は元の品質のままです。
  4. 連続で推演に失敗すると、最低保証進捗が累計されます。最低保証に達すると、次の推演は必ず成功します。品質が上昇すると、対応する最低保証回数は再計算されます。

【設計図の研究】

  1. プロジェクト投資を完了すると、確率で異なる品質の「設計図」を獲得できます。
  2. 設計図の種類や品質によって、研究時に消費する資源の種類と数量が異なります。
  3. 設計図の品質が高いほど、高品質の発明を研究できる可能性が高くなります。また、発明の属性数や属性品質にも影響します。

【創造発明】

  1. 各発明には「生産属性」または「戦闘属性」が複数付与される可能性があり、発明の品質によって属性の数や品質が異なります。
  2. 生産属性は主に経営、資源獲得、生産効率に影響し、戦闘属性は主に名士、兵士、または陣営関連の能力を上昇させます。
  3. 発明は特殊な「奇効」を獲得する可能性もあります。奇効には異なる品質があり、品質が高いほど、効果も通常は強くなります。

【発明陳列】

🏛️ 天工館・展示枠構成一覧

展示館（全4種） 古代華夏 / 古代海国 / 近代華夏 / 近代海国
展示枠（各3種） 生産革新 / 探索拡界 / 生活智造
  1. 「天工館」は「古代華夏」「古代海国」「近代華夏」「近代海国」の4種類の展示館に分かれており、展示館ごとに独立した解放条件があります。
  2. 各展示館にはそれぞれ「生産革新」「探索拡界」「生活智造」の3種類の展示枠があり、各発明には対応する展示館と枠の種類があります。
  3. 発明は、自身に対応する種類の枠にしか展示できず、他の種類の枠には入れられません。
  4. 発明は「陳列」して初めて、提供する属性バフと奇効が正式に発動します。未陳列の発明は、引き続き発明倉庫に保管できます。

【図鑑収集】

  1. 各種の天工館には、それぞれ独立した「発明図鑑」があり、入手したさまざまな発明を記録します。
  2. ある発明を初めて入手すると、図鑑に登録でき、対応する初回収集報酬を獲得できます。
  3. 同じ発明を重複して入手しても、初回収集報酬は再度獲得できませんが、図鑑には首長がその発明で獲得した最高スコアが記録されます。
  4. 各図鑑が指定の収集数に達すると、段階的な収集報酬を受け取れます。図鑑には、サーバー間同盟内でその発明のスコアが最も高い首長も表示されます。

【取引センター】

  1. 月間札を有効化した首長は、「取引所」で他の首長が出品した発明を購入または販売できます。
  2. 「取引可」標記のある発明のみ、出品取引が可能です。陳列、ロック、バインド、またはすでに出品中の発明は、再度出品できません。
  3. 月間札の有効期間中に入手した卓越以上の品質の発明は、研究完了後に「取引可」標記を獲得します。
  4. 発明を出品する際は、販売価格を設定する必要があります。すべての発明は取引通貨「巧金」で価格設定と購入を行います。
  5. 発明は「一口価格」での取引方式を採用しており、他の首長が対応する数量の巧金を支払えば、そのまま購入できます。
  6. 卓越品質の発明は、出品完了後すぐに他の首長が購入できます。伝説以上の品質の発明は、出品完了後にまず「展示期間」に入ります。展示期間中、他の首長は商品を確認できますが、まだ購入できません。
  7. 発明が売却に成功すると、成立価格に応じて一定割合の「取引手数料」が差し引かれます。
  8. 発明が売却された後、売り手が受け取る巧金は手紙で配布されます。買い手は対応する発明をすぐに受け取れます。
  9. 取引で入手した発明には7日間の「取引クールタイム」があり、クールタイム中は再出品できません。
  10. 毎週出品できる発明の数には回数制限があります。今週の出品回数をすべて使い切ると、新しい発明を公開できなくなります。

イベント三、新規イベント秋夜の宝探しを追加

🎑 秋夜の宝探しの詳細（クリックで詳細展開）

【イベント説明】

  1. 秋が訪れ、嫦娥が首長様を招待して、一緒に月餅を切っておいしさを分ち合います～
  2. 月餅の下には小さな報酬が隠されています。切れば獲得できます。
  3. 1箱の月餅をすべて切り終えると、嫦娥が大賞を贈ります。

【切り分けルール】

  1. 各箱の月餅は2～3層で構成され、玉兎は一番外側の層から切り始めます。
  2. 切るたびに、現在の層の月餅をランダムに1つ切り開き、その月餅の下にある報酬を獲得します。
  3. 現在の層を切り終えると、自動で内側の層へ進みます。1箱の月餅をすべて切り終えると、次の箱が開きます。
  4. 各段には月のマークが付いた特別な月餅があります。特別な月餅を切ると、1～3段の月餅を一度に切り開き、その下にあるすべての報酬を獲得できます。

【大賞ルール】

  1. 各箱の月餅には必ず大賞が1つあり、大賞は固定大賞と選択大賞の2種類に分かれます。
  2. 首長は選択大賞の報酬を自由に選べます。本箱の月餅をすべて切り終えると、選んだ大賞を獲得できます。
  3. 固定大賞は盤面内で固定された報酬です。本箱の月餅をすべて切り終えると、固定報酬を獲得できます。

【秋夜の市場】

  1. 首長が月餅を切ると、一定確率で「金色月華」と「白霜月華」を獲得できます。秋夜の市場で対応する道具と交換可能です。
  2. 秋夜の市場では、一部の道具は一定回数月餅を切らないと交換できません。
  3. イベント終了後も、金色月華と白霜月華は回収されません。

【神話瑤姫】

  1. 首長は秋夜の宝探しイベントで、瑤姫の美女玉や、瑤姫の有効化に使う5種類の衣装を獲得できる可能性があります。
  2. 5種類の衣装を集めると、神話瑤姫を有効化でき、神話技能効果を獲得します。

四、新たに収集品精錬機能を追加

  1. 伝説と神話品質の収集品を対象に、新しい収集品精錬機能を開放します。
  2. 伝説と神話品質の収集品を精錬すると、伝説精錬石と神話精錬石を獲得できます。
  3. 伝説と神話の収集品を精錬育成する際は、同じ品質の精錬石を使って、収集品本体の代わりに精錬できます。
  4. 収集品を精錬すると、その特殊スキルと練成スキルは永久に失われます。十分ご注意ください。

五、新しい名士神格システム追加

  1. 品質上昇能力を持つ名士は、すべて神格育成機能が開放されます。
  2. 神髄を使うと名士の神格レベルを上昇できます。指定レベルに達すると、名士の心魔が現れます。心魔を倒すと、名士の神格境地を上昇できます。境地が上昇すると、名士の神性も上昇します。
  3. 名士には神紋も追加され、神印を使って神紋に刻印でき、刻印で神紋のランクが上昇します。
  4. 神紋のランクが指定レベルに達すると、名士の神格境地上限を上昇できます。

六、遠征攻城戦の新機能を追加

攻城段階中に撃破した部隊は、兵士の戦力バフを追加で獲得できます。撃破した部隊数が多いほど、戦力バフも高くなります。

  1. 同盟を変更して新しい遠征グループに入る際、前後2つの遠征グループの開始時間が一致しない場合は、前の遠征が終了するか、現在の同盟が次の期の遠征に入るまで、遠征の挑戦に参加できません。
  2. 途中で同盟を変更するルールを調整しました。各期の世界遠征期間中、初めて同盟を変更した場合、遠征は1日間のクールダウンに入ります。2回目以降は7日間のクールダウンとなります。クールダウン中は攻城に参加できず、前の同盟の最高レベルの反乱軍より高いレベルには挑戦できません。
  3. 世界遠征の1期あたりの継続時間を調整します。今後の新しい世界遠征では、継続時間を30日から45日に延長し、城地の開放時間と遠征報酬も同時に調整します（当期の遠征には影響しません）。
  4. 遠征の最終順位集計後の休戦期間における宣戦ルールを調整します。今後の新しい世界遠征では、中心城地は集計後、毎週土曜日のみ宣戦可能となり、それ以外の時間は中心城地に宣戦できません（当期の遠征には影響しません）。
